How work moves through the harness

Every change, big or small, goes around the same loop. You decide what to build and whether the result is right. The agent does the steps in between.

Guardrails that apply to every stage

The agent cannot skip these. Rule files are always loaded, and automated checks run before every commit and again in CI.

Rules the agent follows

  • Architecture and where each file belongs
  • Code style and naming
  • Testing standards
  • Security (server-side permissions, no secrets in code)
  • Git workflow (never writes to main)
  • When to ask you, and what needs your approval

Automatic checks

  • Formatting and lint
  • Strict type checking
  • Layer and import boundaries
  • Allowed folders and file names
  • Unit tests on every pull request
  • Pull request title format for releases
